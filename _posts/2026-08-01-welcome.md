## 🗺️ 2. 10대 미션 커리큘럼 아키텍처 맵 (System Engineering Matrix)

```text
[ Application Layer ] --------> python-quiz-game / python-budget-app / vanilla-js-portfolio
[ AI & Hardware Layer ] ------> mini-npu-simulator / Prompt-Engineering
[ Data & Storage Layer ] -----> mini-redis / sql-db (SQLite)
[ Infra & Cloud Layer ] ------> cloud-infra-aws (VPC) / linux-system-monitor / cli-docker-git
```

### 📊 10대 프로젝트 핵심 기술 쟁점 요약표

| 미션명 (Slug) | 주요 기술 스택 | 핵심 기술 쟁점 (Core Technical Issues) |
|---|---|---|
| **`python-quiz-game`** | `Python`, `JSON` | 절차지향 코드 vs OOP 데이터 캡슐화 & JSON 데이터 영속화 쟁점 |
| **`mini-redis`** | `Python`, `C DataStructures` | 파이썬 `dict` 없이 로우레벨 이중연결리스트/해시맵 수동 구현 & LRU Eviction 메모리 계측 쟁점 |
| **`cloud-infra-aws`** | `AWS VPC`, `EC2`, `IAM` | Default VPC 보안 취약점 ➡️ 3계층 사설 격리 VPC & 보안그룹 IP 화이트리스트 쟁점 |
| **`sql-db`** | `SQL`, `SQLite` | 1:N 외래키 참조 무결성 `RESTRICT` vs `CASCADE` 정책 & ORM 없는 16선 고속 SQL 쟁점 |
| **`linux-system-monitor`** | `Shell Script`, `UFW` | SSH 22번 포트 변경 서버 요새화(Hardening) & Log Rotate 회전 파이프라인 쟁점 |
| **`cli-docker-git`** | `Docker`, `Linux`, `Git` | "내 컴에서만 잘 됨" 문제 방지 Custom Dockerfile & 바인드 마운트(`-v`) 영속성 쟁점 |
| **`python-budget-app`** | `Python Standard Lib` | 4계층 아키텍처(SoC) 분리 & 전원 차단 시 파일 0바이트 파손 방어 **원자적 쓰기(Atomic Write)** |
| **`mini-npu-simulator`** | `Python`, `Linear Algebra` | NPU가 AI 연산에 빠른 이유: MAC 연산 시뮬레이션 & 2D 배열 1D Flattening 캐시 최적화 쟁점 |
| **`vanilla-js-portfolio`** | `Vanilla JS`, `CSS3` | React 없이 순수 JS 단방향 상태 관리 (Event ➡️ State ➡️ Render) & 4단계 UI 상태 머신 쟁점 |
| **`Prompt-Engineering`** | `LLM`, `ChatGPT`, `Claude` | 최신 4종 LLM 벤치마킹 & 환각(Hallucination) 제어 프롬프트 검증 쟁점 |

## 🚀 3. 블로그 탐험 가이드

모든 포스팅은 다음 4단계 구조로 작성되었습니다:
1. **💡 미션 개요 및 핵심 질문**: 왜 이 미션이 필요한가?
2. **⚡ 깊이 있는 기술 쟁점 (Deep-Dive Debates)**: 트레이드오프 분석 및 코드 비교
3. **🛠️ 실제 소스코드 하이라이트 & 아키텍처**: 실제 구현 코드 설명
4. **📝 최종 공학적 성과 및 교훈**: 얻어낸 시스템적 인사이트

상단 메뉴의 **`🌐 Portfolio`** 링크를 통해 프로젝트 포트폴리오를 확인하실 수 있으며, **`📝 CMS 글쓰기`** 링크를 통해 웹에서 바로 글을 작성하거나 수정할 수 있습니다.
