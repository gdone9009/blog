AWS 퍼블릭 클라우드 생태계에서 사설 격리 네트워크(VPC)를 밑바닥부터 직접 설계하고 엔터프라이즈급 인프라 보안 경계를 구축한 이야기입니다. 🛡️

VPC(`10.0.0.0/16`), Public Subnet, Internet Gateway(IGW), Route Table 및 보안 그룹(Security Group)을 통해 웹 트래픽을 안전하게 수용하는 아키텍처를 수립했습니다.

인프라 패킷이 전달되는 흐름(Packet Flow)과 IAM 최소 권한 원칙의 정수를 체득했습니다! 🚀
